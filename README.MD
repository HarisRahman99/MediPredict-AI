# MediPredict AI

MediPredict AI is a web-based healthcare application built using Flask and Machine Learning.

## Features

- Heart Disease Prediction
- Chronic Kidney Disease Prediction
- OCR-based Medical Report Upload
- Diet Recommendations
- User-friendly Dashboard

## Tech Stack

- Python
- Flask
- HTML/CSS/JavaScript
- Scikit-learn
- Pandas
- NumPy
- EasyOCR

## Installation

```bash
pip install -r requirements.txt
python app.py
